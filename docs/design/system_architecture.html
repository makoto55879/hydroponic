システムアーキテクチャ設計 v1

作成日: 2026-06-13

本ドキュメントは、3Dプリンター製モジュール式水耕栽培システムの全体構成と各モジュールの設計方針をまとめたものです。

1. 全体構成図

システムは「壁面固定レイヤー」「栽培レイヤー」「水管理レイヤー」「照明レイヤー」の4つの階層で構成されます。

2. モジュール詳細設計方針

2.1 Skadis互換ペグボード

  • 役割: 壁面への固定とプランターの懸架。
  • 素材: PLA（水に触れないため）。
  • 寸法: Bambu Lab A1で印刷可能な最大サイズ（約220×220mm）を基本単位とする。
  • 固定方法: 皿穴を設け、市販の長めの豆ピン（画鋲）を多数使用して壁に固定。

2.2 プランターモジュール

  • 役割: 植物の保持と水の経路（NFTカスケード）の形成。
  • 素材: PETG（耐水性・耐薬品性重視）。
  • 構造:
  • 背面にSkadis互換のフック（爪）を一体化または別パーツで取り付ける。
  • 内部に傾斜を設け、水が滞留せず一方向に流れるようにする。
  • 水位が一定（数mm〜1cm程度）に達すると、下の段へ水が落ちる「オーバーフロー管」または「スリット」を設ける。
  • 上部は市販のネットポット（水耕栽培用カゴ）がはまる丸穴を開けたフタ構造とする。

2.3 下部タンクとポンプ

  • 役割: 養液の貯蔵と循環。
  • 構成:
  • タンクは水漏れリスクを避けるため、100円ショップやホームセンターのプラスチックコンテナ（容量5L〜10L程度）を使用。
  • ポンプは流量調整が可能な小型水中ポンプ（揚程1.5m〜2m程度）を使用。
  • タンクにはフタをし、藻の発生（遮光）とホコリの混入を防ぐ。

2.4 照明（育成ライト）ブラケット

  • 役割: 日照不足を補うためのLEDライトの固定。
  • 構造: プランターモジュールの下部、またはペグボードに直接取り付けるアーム状のブラケット。

3. 次の設計ステップ

  1. Skadis互換フックの寸法出しとテストプリント。
  2. プランターモジュール内部の流路（カスケード構造）の3Dモデリング。
  3. ネットポットのサイズ選定（市販品に合わせるか、3Dプリントするか）。
